# 楽器・マウスピースカタログ 初版データ (2026-08-27)

サックス練習支援アプリのユーザープロフィール用カタログ。ユーザーは部分一致検索でここから選ぶ(自由入力なし)前提。
後で JSON 化しやすいよう「ブランド → モデル → (開き)」の階層で表にしている。

## 凡例(確認状況)

| 記号 | 意味 |
|---|---|
| ◎ | メーカー公式サイト等の一次情報で確認 |
| ○ | 販売店・専門店・専門メディアの記載で確認(Web検索で実在確認済み) |
| △ | 定番として広く知られるが今回の検索では個別確認していない(一般知識。JSON化前に要再確認) |

型番は「検索で実在確認したものだけ載せる」方針。△は型番の実在自体は確度が高いが、表記ゆれ(例: 世代サフィックス)の再確認を推奨。

# 2. マウスピース

## 2.1 開き(ティップオープニング)表記体系の整理

ブランドごとに表記が違うため、カタログのデータ構造は「ブランド固有の表記文字列」をそのまま持つのが安全(数値mmへの正規化は別フィールドで任意)。

| 表記体系 | 例 | 採用ブランド |
|---|---|---|
| 文字+スター(C→Fで開く。*は中間段階) | C, C*, C**, D, E, F | Selmer S80、ヴィンテージSoloist |
| 3桁数字 = 1/100mm | 170, 180, 190, 200 | Selmer S90 / 現行Soloist / Concept(単一フェイシング) |
| 記号型番(楽器接頭辞+番号。番号自体は開きの通し番号) | AL3 / A28 / T27 / T75 | Vandoren(Optimum, V5, V16, Java) |
| 数字+チェンバー/フェイシング記号 | 5MM, 6MM(6M=NY Bros系) | Meyer |
| 数字+スター(*=半段大きい) | 5\*, 6\*, 7\*, 8 | Otto Link, Dukoff, JodyJazz, Guardala系 |
| 数字+\*3(開き番号+フェイシング番号) | 4\*3, 6\*3, 7\*3 | Claude Lakey |
| ボア記号+フェイシング番号 | S5, S6S, M7, M8 | Beechler(S/M/L=ボア径) |
| D+数字+M | D5M〜D9M | D'Addario Select Jazz |
| 数字+C(クローズ寄り標準) | 3C, 4C, 5C, 6C | Yamaha Standard |
| インチ小数(実測値併記文化) | .105, .110 | 米国系全般の併記(Link 7\*=.105等) |
