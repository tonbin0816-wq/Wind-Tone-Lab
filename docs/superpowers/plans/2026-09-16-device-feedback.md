実装部隊（Opus / jisso）が便ごとに実装する。** 各便は3ゲート（vitest / pitch-test / vite build）
と合格ラインの数え直しと変異試験で統括が検収する。前例: `2026-09-15-designbook-adoption.md`。

本人指示「これを修正するならここもという点があれば合わせて修正」に従い、各項目に
**波及**（同じ理由で直すべき別の箇所）を書いた。波及は担当外扱いにしない。

## §0 共通の前提（全便に効く）

- 作業場所は worktree `view-other-user-data-ebb07d`。`git stash` を素で使わない。`git push` しない
- **値を発明しない。** 色・寸法・時間は `src/index.css` の `:root` のトークンだけ
  （角丸は `--r-1`/`--r-2`/`--r-full`、動きは `--d-fast/base/slow`、文字は `--fs-*`）。
  利用者の画面の文字の最小は `--fs-xs`=12px（据え置きの2定数は触らない）
- **正典（`design/north-star-measure.html` / `design/canvas/*.dc.html` / DESIGN-SYSTEM の表）が動く
  変更は、正典を先に書き換えて検査を追随させる**（B10 案ア・便C の作法）
- 語彙: 「計測」（セッションと言わない）/ 楽器は S.Sax 等 / 「機材」「機種」と言わない / 中黒で区切らない
- コメントは `{/* */}`。`//` は JSX の子として画面に出る
- 綴りを数える検査はコメントを剥がしてから（`codeOf()`）。テキスト検査はビルドを見ない → 3ゲート全部
- コミュニティの「参加してプロフィールを作る」を押さない（本番 Firestore に実アカウントが出来る）。
  確認は使い捨ての probe で、終わったら消す
- 通知は `ActionNotice`（App の根に1つ）を使う。新しい通知面を作らない
- `firestore.rules` を変える便は、**ルールの本文を成果物として出すだけ**（公開は本人がコンソールで。
  順序は ルール公開 → アプリ配信）

### C11 利用規約・プライバシーポリシーに戻る手段
### C12 戻るとマイクの許可を求める画面が出て反応が無くなる
- 原因の見立て: `NavRow external` は `target="_blank"`（`1072`）だが、本人の実機では**同じ画面で
  開いている**（スワイプで戻れる = SPA から離れている）。戻ると SPA が**再起動**し、計測タブの
  `useEffect`（`4080-4087`）が `startListening` → 許可ダイアログ → 起動直後で AudioContext が
  suspended のまま応答しない、という筋
- 直し方（C11・C12 を1つで）: **アプリの外へ出ない。** `LegalSheet` を新設し、`fetch("/terms.html")`
  で同じ origin の静的 HTML を取り、`<body>` の中身を `BottomSheet` の中に描く（`legal.css` の
  クラスはそのまま効かせる）。シートの上に **× / 閉じる**（左上。`BottomSheet` の作法どおり
  つまみ + Esc + 暗幕タップも効く）。`NavRow` の `external` は `onClick` に変える。
  お問い合わせ（`mailto:`）はそのまま
- 合格: 規約・ポリシーを開いて閉じても `location` が変わらない（`history.length` 不変）。
  `public/terms.html` `privacy.html` は**そのまま**（ストア審査の URL として要る）
- **C12 の実挙動は実機待ち**（Chrome ではマイクの許可経路が再現しない）。アプリの外へ出なくなれば
  経路ごと消えるが、別の原因なら残る。実機で再現したら `startListening` の起動時の経路を別便で追う
