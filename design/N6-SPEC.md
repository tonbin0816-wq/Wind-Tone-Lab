## 1. ヒーロー（推移カード）

現行 `MyDataSection` 冒頭の紺のカード。

| | 内容 |
|---|---|
| 上段 | 左に「今日」、右に期間セレクタ「1ヶ月 ▾」（**素テキスト+▾**。枠なし。F-72系の作法） |
| 主数値 | 平均差分 `+1.2¢`。単位は小さく。色は §1.5 の機能色（Great=ミント等）に連動 |
| 評価 | 主数値の右にピル `Great` |
| 副次行 | `±3.4¢ · 平均 −0.8¢`（標準偏差 · 対象期間平均）の1行 |
| スパークライン | 0中央対称、0の線は破線 |
| **削除** | 脚注「1ヶ月 ・ 12セッション」（本人指示「青いカード部分のテキストが多い」／対照表で消す候補） |

期間セレクタ9種は現行のまま全て残す。

## 2. 指標行（累計 / 最新）

現行の「My Data」カード（2×2の4枚）と「最新セッション」カード（2×2の4枚）を、**3指標×2行**に置き換える。

```
累計            17.6dB      1195Hz     −21.9dB
                HNR         重心        音量
最新            18.2dB      1214Hz     −21.4dB
2026/08/09      HNR         重心        音量
```

- **平均差分の列は削除**。ヒーローに出ているため（モックのキャプション明記）。
- 行ラベルは左に「累計」「最新（下に yyyy/mm/dd を9px）」。
- **累計は全期間**（モックのキャプション「累計(全期間)」）。ヒーローの期間セレクタとは連動しない。
- 数字タップで**現行どおり**音名軸グラフに切り替わる（再タップで戻る）。目安があれば破線を重ねる。
  **目安Δは常時表示をやめ、グラフ側に出す。**（情報は失わせない。常時表示の Δ を消すのはモックの行に列が無いため）
- 「目安未設定」の表示、および対象セッション0件のときの空状態文言は現行のまま残す。
- カードの枠は作らない（F-77で枠線は撤去済み）。

## 3. セッション一覧

| | 内容 |
|---|---|
| 見出し | `セッション 5/12`（絞り込み中のみ分数。それ以外は総数） |
| アップロード | 見出しの右に**塗りボタン**「↥ 録音をアップロード」（紺地・白文字）。輪郭だけのフィルタピルと形言語で区別。解析中は押せず「解析中…」 |
| 絞り込み | 現行の沈めた「絞り込み」ブロックを廃し、**ピル4つを横一列**に: `1ヶ月 ▾` / `リード ▾` / `奏者 ▾` / `クリア`。クリアはアクセント色で、絞り込みが効いているときだけ出す（現行と同じ条件） |
| 行 | `2026/08/09 19:04` の下に副次行 `V16-3 #4 · 自分 · 12:24`。リード表記は `shortBoxLabel` 系の短縮形（N-4aと同じ）。アップロード由来は右端に `↥` |
| 行タップ | セッション詳細（現行のまま） |
| 空状態 | 現行の2種の文言をそのまま残す |

- **時間 `12:24`** は保存されていないので、フレームの最後の `t`（秒）から mm:ss を導く。フレームが空なら時間の区画ごと省く。
- ピッチ差分は行から出さない（本人指示・実施済み）。
- 一覧の高さ制限とスクロールは現行のまま。

## 4. 「…」メニュー（子タブ行の右端）

現行のごみ箱ボタン（選択削除モードの入口）と、選択中に出る「一括リード変更」を、**子タブ行の右端の「…」の中**へ移す。

- 「…」→ `セッションを選んで削除` / `選んだセッションのリードをまとめて変更`
- 削除モードに入った後の見た目（チェックボックス・キャンセル・n件を削除）は現行の作法を維持。削除は `--c-danger` の塗り。
- **0件のときは押せる項目を出さない**（F-77で踏んだ罠と同じ形。0リードの「…」で使えない削除が出ていた）。

## 5. アップロードの進捗・完了通知

**データタブの上端に浮かせる**（モック mini）。

- 進捗: 「読み込み中」+ 3px の細い横棒 + 右に `64%`
- 完了: 「解析が完了しました」+ `★ 目安に設定` + `×`
- 動画で自動再生がブロックされたときの「解析を開始」も同じ場所
- 無音ファイルのエラーは共通モーダルのまま
- 「目安に設定」の中身（このセッション / この奏者の平均 + 命名 + 同名マージ）は現行のまま

## 機能を1つも落とさないこと

本人の決定「モックと現行がぶつかったら**機能を残す**」。以下は形が変わっても消さない:
期間セレクタ9種／音名軸グラフ／目安Δ／目安未設定の告知／奏者・リード・期間の絞り込み／
クリア／選択削除／一括リード変更／アップロード進捗・完了通知・目安に設定／
アップロード由来の印／空状態文言／セッション詳細への遷移。

## 出してはいけないもの

- Ficus のアイコン・植物の要素（本人が明確に見送りを指示）
- 長い説明文（「趣旨がずれてる」と名指しで指摘された）
- カードの枠線（F-77で撤去済み）
