# F-106〜F-109 + N-10 — 凍結仕様（2026/08/17 本人指示・実機確認第4陣）

## F-106【最優先・再修正】削除モードで先頭行だけチェックが出ない

**前回の対処（常設 checkbox + `display` 切替）でも実機では直っていない**（本人確認済み）。
Chrome では再現しないので、**iOS Safari 固有のレイアウト／ペイントの取りこぼし**として扱う。

本人のスクリーンショットから読み取れる事実:
- 削除モードに入った直後: **先頭行だけチェックボックスが無い**（2行目以降は正常）
- その状態で先頭行をタップ: チェックは付くが、**先頭行のテキストが字下げされず、チェックと重なる**
- つまり「先頭行だけ、モード切替時のレイアウト更新が反映されていない」

**方針転換（これが仕様）**: **行ごとに要素を出し入れするのをやめる。**
- チェックボックスは**常に DOM にあり、常にレイアウトに参加する**（`display` も `visibility` も切り替えない）
- モードの切替は**祖先（一覧のコンテナ）に付けるクラス1つ**だけで表現する
  （祖先のクラス変更は subtree 全体の style 再計算を必ず伴うので、行ごとの取りこぼしが構造的に起きない）
- 行のテキストの字下げも、**行ごとの style ではなく祖先クラス経由の CSS** で与える
- モード外でチェックボックスが見えない/触れないようにするのは `opacity: 0` + `pointer-events: none`
  （**レイアウトは動かさない**）。ただしモード外で 44px の当たり判定を奪ってはならないので、
  幅は 0 にせず、行の左に常に確保する — **モード外の行の見た目が変わることは許容する**
  （字下げが常時入る）。**見た目より、モードで壊れないことを優先する**という判断。
  ※ 字下げ量が気になる場合に備え、モード外の確保幅は小さく（例 20px 相当）してよい。
- `contain` / `content-visibility` / `will-change` / `transform` を一覧の行や
  スクロールコンテナに使っている箇所があれば**外す**（iOS の再ペイント取りこぼしの典型要因）。
  外した場合は理由を報告に明記。

**検査**: 「モード外/モード内のどちらでも、全行の DOM 構造が同一であること」
「切替で行ごとの style / display が変わらないこと」「祖先クラスだけが変わること」を固定する。

## F-107 横スワイプ中にページ間の間隔が詰まる

リードタブ（登録⇄比較）・データタブ（My Data⇄分析）の `SwipePager`。
**指で引いている最中だけ、隣のページとの間隔が詰まって表示される。**
原因は track が「幅100%のページを隙間なく並べたもの」で、静止時は隙間が見えないが
ドラッグ中は隣のページが露出するため（＝もともと隙間が無い）。

**仕様**: ページ間に**一定の溝（gutter）を常に確保**し、ドラッグ中も静止時も同じ間隔を保つ。
- 溝の値は既存トークンから採る（`--sp-*`。新しい値を発明しない）
- 静止時のページ位置（各ページの左端）は**溝を含めて計算**すること
  （`translateX(-i * 100%)` のままだと溝の分ずれる。`calc(-i * (100% + 溝))` 等）
- 「進む/戻る」のしきい値・抵抗・終わり方（§6.3）の規則は**変えない**
- 純関数（`swipePagerTrackStyle` / `swipePagerNextIndex` 等）に溝を織り込み、総当たりで検査

## N-10 My Data 刷新（本人: 案K採用 + 変更点）

正典 = `design/mydata-zero-proposals-2.html` の**案K**。本人の追加指示:
> 表示されるグラフは一つで、ピッチ・重心・音量・HNR の数字カードは残して、
> それぞれをタップするとそのグラフが表示される仕組みに変更

**確定仕様**:
1. **上部＝蓄積量の数字**（案K）: `46回 / 12.5時間 / 3,120音`（セッション数・総演奏時間・計測した音の数）。
   小さいラベル付き。楽器・期間セレクタは右上に継続。
2. **数字カード4枚**（ピッチ＝平均差分 / HNR / 重心 / 音量）を横並び。
   **1枚が選択状態**（既定＝ピッチ）。タップでその指標に切り替わる。
   カードには「その期間の平均」と、直近日（今日 or 直近の記録日）の値を出す。
3. **グラフは常に1枚だけ**。選択中の指標の音名軸折れ線を描く。
   線は **期間平均（薄）／直近日（濃）** の2本 ＋ **ばらつきの帯**（案Kの特徴）。
   目安の破線・Δ は**出さない**（N-8 の決定を継続）。
4. **セッション一覧**: 見出しの右に **「↥ 取り込み」と「選択」**（＝削除モードの入口）を置く（F-108）。
   行タップで詳細、`↥` 印、絞り込みピルは継続。
5. 紺のカードと評価ピル（Great 等）は**廃止**（案Kの前提）。

**落とさない機能**: 期間セレクタ9種 / 楽器セレクタ / 絞り込み（リード・奏者・期間）/
アップロードと進捗・完了通知 / 一括リード変更 / セッション削除 / 直近日フォールバック（ラベルは日付）。
