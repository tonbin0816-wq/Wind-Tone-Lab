## 1. 折れ線の向きは変えない

縦軸＝音名（上から下へ）／横軸＝選んだ数値、という向きは **N-9 から不変**。
正典 `#13a` が足したのは次の3つだけ。

| | 正典 | 実装 |
|---|---|---|
| **行の縞** | オクターブ単位で交互に極薄い面 | `pivotOctaveStripes`。地は体系でいちばん淡い `--c-sunk`。**行が音名のときだけ**（`rowIsNote`）。音名でない次元に「2行ごとに交互」のような**正典に無い規則を発明しない** |
| **縦の目盛り線** | 5本。**0線だけ濃い** | `pivotTickValues(lo, hi, 5)` ＋ 0の線は別に引く（`--c-line-strong`）。目盛の線は `--c-line` |
| **凡例の位置** | グラフの**上**。左に系列、右端に単位 | `SeriesSwatch` ＋ `pivotUnitOf(metricDef)`。グラフ下にあった指標名は単位が引き継いだ（二度言いを作らない） |

**行高 25px / 点 r2.8 ＋ 白フチ1.1px / 線幅2px** は正典の実数をそのまま採る
（`PIVOT_ROW_H` / `PIVOT_DOT_R` / `PIVOT_DOT_RING`）。

### 1.1 0 の目盛を「寄せない」— 初版の欠陥と訂正
初版は「**いちばん 0 に近い目盛を 0 ちょうどへ寄せる**」形にしていたが、
`lo = -1 / hi = 9` では**左端の目盛が -1 なのに「0」と表示される**（軸の端の値を偽る）。
0 の線は目盛とは**別に**引き、ラベルが重なる目盛を1つだけ譲る（`pivotCrowdedTickIndex`、
しきい値 `PIVOT_TICK_MIN_GAP_PX = 18`）。**0 のラベルは必ず出す。**

## 2. 操作部

### 2.1 条件のチップ行
`条件` のラベル ＋ 適用中フィルタのチップ ＋ 追加用の `＋`（破線）。

- チップ: 地 `--c-accent-tint` ／ 文字 `--c-accent` ／ 11px・600 ／ 角丸 `--r-sm` ／ 余白 `4px 9px`
  （正典の `#E4EAF2` / `#1D4E89` / `7px` の写像）。**枠は透明で場所だけ残す**
- `＋`: **破線の枠だけ**（地は持たない）。芯1「同じ物に枠線と違う地を両方与えない」
- チップの文字は `pivotFilterChipText` の1箇所（値の畳み方を2箇所に書かない）。
  値を選んでいない条件は次元名だけ、選んでいれば値そのもの、多すぎれば「他n」に畳む

**機能は1つも落とさない。** 正典は条件を1行に畳んでいるが、現行の編集UI
（12次元・値チップ・音域帯まとめ選択・日付/日数範囲・条件の削除）は**チップか「＋」を押すと下に開く**。
既定は畳んだ状態（`filterEditorOpen`）。

### 2.2 3カラムのセレクタカード
`並べる軸` / `数値` / `分け方`。中身は N-9 の `縦軸` / `横軸` / `指標` と**同じ状態**
（`pivotRow` / `pivotMetric` / `pivotCol`）で、正典に合わせて**名前だけ**を変えた。

- 器は `.surf-sunk` の中の `.card`（地・角丸・padding は作法が持つ。インラインで書かない）
- `grid-template-columns: 1fr 1fr 1fr` / `gap: var(--sp-2)`（正典の `8px`）
- **中央の列だけ左右に罫**（正典どおり。列の境界を余白ではなく線で示す）
- 部品は共有の `PlainSelect`（素のテキスト ＋ ▾）。`strong` を足して値だけ 600 にする
  （正典の 13px/600。**既定 false なので既存の呼び出しは 1px も変わらない**）
- 旧 `select.pivot-axis-select` は**規則ごと削除**（読み手ゼロ）

### 2.3 表題と説明は残す（正典に無いが本人指示が上位）
F-99 の本人指示「分析は自分で軸を選んで初めて機能するページ。最初に一定の説明が要る。
PIVOT の文字があれば Excel も想起できる」に従い、`PIVOT` の表題と1行の説明は残す。
**説明の語はセレクタの名前と揃える**（条件・並べる軸・数値・分け方）。

## 4. ついでに直したもの
**N-5b**（PIVOT の日付フィルタが常に1日前を表示する）。
`new Date(...).toISOString().slice(0,10)` は **UTC の暦日**で、JST では 00〜09時に常に前日が出る。
`App.jsx:1292` が名指しで禁じていた最後の2箇所で、D-2 でこの行を触るので同時に `localDayKey` へ直した。
