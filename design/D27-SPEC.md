> mydataの一番したの平均差分とかHNRとかの比較する二つの指標（○○×○○）
> のところが一方選択中はもう一方に出ないことになっているせいでサクッと入れ替えたいときに

**本人の認識は正しい。** 第7陣で「相互排他をやめる」話をし、**自動入れ替え**で決まっていた。

## §1 いまどうなっているか（実際に読んで確かめた）

`src/App.jsx` の My Data 下部（`DataOptionSheet` を開く箇所）:

```js
items={myDataSeriesOptions(hasIdeal, pair[sheetSide === 0 ? 1 : 0])
  .map((o) => ({ key: o.key, label: myDataSeriesLabel(o.key, day.label) }))}
```

`myDataSeriesOptions(hasIdeal, taken)` は `taken` に一致する系列を**列から消す**。
`setSeriesAt` にも入れ替えの処理は無い。

出どころは **D-9 §1 の本人指示**「左右で同じものを選べないように、一方で選ばれているものは
そもそももう一方の選択肢から削除するようにして」。
**そのときは正しかった。** 第7陣で本人が方針を変え、いまはそれが不便になっている。

## §3 直し（凍結）

### 3.1 選択肢から消すのをやめる

シートには**4つの候補すべて**を出す（目安が未設定なら目安だけは従来どおり出さない
── これは F-77「押せない選択肢を出さない」で、別の理由）。

`myDataSeriesOptions` の `taken` を渡している呼び出しを**やめる**。
引数そのものを消すかどうかは実装の判断でよいが、**読み手ゼロの引数を残さないこと**
（D-14 で `metricKey` を「無視する引数を残すと嘘の契約が残る」として受け口ごと落とした前例に倣う）。

### 3.2 もう一方で選ばれているものを選んだら、**入れ替える**

```
1本目 = 平均差分, 2本目 = HNR のとき
  1本目を押して「HNR」を選ぶ → 1本目 = HNR, 2本目 = 平均差分
```

**2タップで入れ替わる。** いまは「入れ替える」という操作が存在しない（片方を第三の値に
逃がしてから戻す、という3手以上が要る）。

### 3.3 「左右が同じ」は今までどおり構造的に起こさない

いまは「選択肢から消す」ことで防いでいる。それをやめるので、
**`myDataSeriesFallback` を必ず通す**形で防ぐこと（この関数が
「左右が同じにならない」の唯一の答えであり続ける。規則を2箇所に持たない ── 罠18）。

### 3.4 見た目

**押す物を増やさない。** チップの形・位置・当たり判定は変えない。
シートの行が1つ増えるだけ。
「いまもう一方で選ばれている」ことを行に添えるかどうかは実装の判断でよいが、
**新しいトークンを発明しないこと**、また**添えるなら、それが何を意味するか（押すと入れ替わる）が
1行で分かること**。添えないほうが素直なら添えなくてよい。

## §4 波及（**必ず確かめること**）

- **検査 27.4「D-9: もう一方で選ばれている系列は選択肢から消える」**
  （`scripts/pitch-test.mjs:15246` 付近）は、**本人が方針を変えた挙動を固定している**。
  書き換えること。**消すのではなく、「入れ替わる」を固定する検査に置き換える**
  （罠: 正しい修正を止める検査を残さない）
- 同じ形の「もう一方から消す」が**他の画面にも無いか**を探すこと
  （本人の常設指示「同じように修正したほうがいい箇所があれば同じく修正」）。
  ただし **F-77 の「押せない選択肢を出さない」は別の規則**なので巻き込まないこと
  （目安が未設定のときに「目安」を出さないのは正しいまま）
- `src/App.jsx` の D-9 由来のコメント（「もう一方で選ばれている系列は列から消す」）が
  2箇所以上ある。**事実と合わなくなるので直すこと**（罠: コメントが実装より強い主張をする）

## §5 検査で守れること / 守れないこと

**守れる**:
- シートに**4候補すべて**が出ること（目安の有無の規則は従来どおり）
- もう一方で選ばれているものを選ぶと**入れ替わる**こと（純関数で数値として確かめる）
- **左右が同じになる操作が存在しない**こと（`myDataSeriesFallback` を通ることを振る舞いで固定）
- 目安を消したときの落とし先が従来どおりであること

**守れない（実機待ち）**:
- **「サッと入れ替えられる」感触。** 2タップになったことは構造で示せるが、
  本人が「入れ替えたい」と思ったときに迷わないかは実機でしか分からない
