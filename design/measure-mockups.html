Ficus / Design Phase 01 — 計測タブ

1メートル先の画面は、
読ませずに伝わるか。

両手は楽器、口はマウスピース、スマホは譜面台の上。演奏中サーフェスは普通のスマホ画面ではありません。 今の計測タブは全体が12px基調の「手元で読む」設計になっています。ここでは演奏中の見え方だけを3通りに作り分けました。 下の操作卓が3案すべてを同時に動かします——同じ音、同じズレで並べて見比べてください。

軸1 — ズレの伝え方

横位置で読ませるか（線）、中心の環の変化で見せるか（環）、画面全体の色で周辺視野に届けるか（面）。3案はこの1点で分かれています。

軸2 — 「育てる」を計測タブに置くか

茎のように伸びる一本線（線）、年輪として楽器そのものに組み込む（環）、この画面には一切置かない（面）。データタブが主戦場なので、置かない選択も正解になり得ます。

選んだあとに起きること

1案を選ぶ、あるいは「Aの線でBの年輪」のような組み合わせでも構いません。方針書どおり、選ばれた画面で使う分だけを色トークン化していきます。

  1. 選択
    A / B / C、または要素の組み合わせを指定。
  2. その画面分だけトークン化
    470箇所の一括置換はしません。計測タブで使う色だけを CSS変数に通します。
  3. 実装 → ビルド＋ピッチテスト
    npx vite build と 3811件のピッチテストを必ず通します。
  4. 実機で確認
    iPhone の PWA 全画面は再現できないため、要所でスクショをお願いします。
