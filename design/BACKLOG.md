## この文書の使い方（ループの運用ルール）

**フローの正典は `design/LOOP.md`。** ここには台帳としての約束だけを書く。

- **残作業 = このファイルの `[ ]` 項目がすべて**（P0 → P1 → P2 → P3 → C の順に消化）。
  完了した項目は末尾の「**完了記録（罠と経緯の日誌）**」セクションへ移す。
- 本人の実機フィードバックは **F-番号** で採番して記録する（次の番号は直近の F を見る）
- 1周終わったら: `[x]` にして完了記録へ移動 + 踏んだ罠を項目の下に追記 +
  規範化すべきことは `DESIGN-SYSTEM.md` へ + 再発防止の検査は `scripts/pitch-test.mjs` へ

**禁止事項**
- `DESIGN-SYSTEM.md` に無い値を新しく作ること
- 1周で複数項目に手を出すこと（差分が検証不能になる。ただし同じ画面・同じ根本原因は束ねてよい）
- 計測精度に関わるロジックを触ること
- `pitchBarColorRGB` の緑/橙/赤の意味を変えること
