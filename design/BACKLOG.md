## 罠の目録（毎周これだけは読む。全て実際に起きた事故の蒸留）

1. **検査名は実際に検証している内容しか名乗らない**(言い過ぎで通算17回差し戻し)。十分条件でないなら「十分条件ではない」と書く。
2. **純関数を守っても配線が無防備なら意味がない。** 描画側が正しい引数で呼ぶことまで固定する。錨は**呼び出しに隣接する綴り**(「コンポーネント内のどこかにあれば通る」は張りぼて)。
3. **期待値は正典(design/*.html)か実装の外から読む。** 定数の定義を同じ式・同じ定数で書き直した検査は恒真。
4. **箇所数の釘付け禁止**(正しい修正を落とす)。縛るなら集合で。件数固定が許されるのは、その件数が不変条件そのものであるときだけ。
5. **明文で禁じるだけの規則は破られても誰も気付かない。** 検査を足すか、構造的に不可能にする(例: .taptext の overflow: visible !important)。
6. **画面に出る文字は画面から読んで確かめる**(幅や桁を測っても文言の誤りは出ない。「スペクトル重心」事故)。
7. **測っていない数値を書かない。** 他人の測定値は測り方ごと引用。**別オリジン比較は面積・形・相対距離だけ**(座標は保存状態で16pxずれた)。
8. **§6.3 ジェスチャー: 終わり方の数え落としで4回固着。** 中断の終端は対象判定より前。touchcancel は中断(指を離した意思表示ではない)。下端シートは上向きを受け付けない。
9. **codeOf() は accept="audio/*" の /* をコメントと誤認して数百行消す**(JSX に使用禁止)。codeOf 済み文字列への indexOf("//…") は常に -1。pitch-test は JSX を評価しない(描画が壊れても緑になり得る)。
10. **Browser pane**: rAF 不発火・トランジション停止 → 判定は inline style。elementFromPoint は整数1px刻み(x.5 で44→43に誤測)。マイク拒否の覆いが奪う → 計測中だけ隠して必ず戻す。**HMR 失敗で古いコードを測る事故** → served コードの綴りを確認してから測る。
11. **変異試験は単独逐次**(F-94: 並列は速度検査が偽 KILL を生み、campaign 全滅が2回)。複製は一意名で `src scripts design index.html package.json` を含め、終わったら必ず削除。
12. **IndexedDB はキー単位復元・clear()/deleteDatabase 禁止。** プロファイルごとに基準が違う(着手時スナップショットを取る)。エージェントは git commit/push 禁止。
13. **Python open(p,"w") は CRLF 化して git 差分に出ず検査12件が落ちた。** LF を維持する。
14. **UTC の暦日は JST 00〜09時で前日にずれる**(開封日で箱が割れた)。暦日は localDayKey。
15. **ネイティブ部品の実寸・<label>活性化・セーフエリア・実指の感触は Chrome で判定不能。** 「実機待ち」と明記し、合格根拠にしない。

### 踏んだ罠（次の担当へ）

1. **`overflow:hidden` の切り取りは padding box で起きる**。`SwipePager` の viewport が
   `overflow:hidden` なので、その中のカードは負マージンを付けても**そこで切られる**。
   viewport に **margin（外へ）+ padding（同量を内へ）** を対で当てると、
   ページの幅（flex の 100% = content box）を 1px も変えずに切り取り線だけ外へ出せる。
   ただし `box-sizing: border-box` なので **`width:100%` のままだと padding ぶん幅が縮む**
   （`width:auto` にすること）。
2. **transform を持つ祖先の中の `position:fixed` は画面基準にならない。**
   `SwipePager` の track は transform を持つので、その子孫に浮かせるボタンを置くと
   track 基準に配置されてスクロールで動く。`createPortal` で body へ出す。
   その代わり**「今どのページか」を自分では判断できない**ので、呼び出し側が `pageActive` を渡す。
3. **軸を短くしても点は短くならない。** `NoteAxisLineChart` の折れ線は `i < plotN` で回すが、
   円（点）は `Object.entries(byIdx)` の全キーを描く。軸の音数を減らした瞬間に
   **点だけが軸の外に並ぶ**（実測で発見。線・帯は正しいので数え落としに気付きにくい）。
   縦のスケールも同じ理由でずれる。**`byIdx` に入れる時点で落とす**のが唯一の直し方。
4. **「役目を終えた」のような語をファイル全体で探す検査は、過去の同じ記述を拾って恒真になる。**
   旧正典には N-10 の「data-tab-final.html は役目を終えた」が既にあり、
   N-11 の注記から同じ語を消しても検査が通った（変異試験で生存）。**注記の中へ走査を絞る**こと。
5. **Bash のヒアドキュメント経由で正規表現を書くとバックスラッシュが1段余分に落ちる**。
   `\\r?\\n` が実際の改行になり、`\\b` が backspace になった（検査ファイルを壊した）。
   バックスラッシュを含む書き換えは **Write/Edit ツールか、ファイルに書いた node スクリプト**で行うこと。
6. **`git ls-files` ベースの複製には未追跡の正典が入らない。** 新しい正典
   （`design/mydata-v2-proposals.html`）は未追跡なので、複製ツリーで検査が
   ENOENT で落ちた。複製を作ったら**まず検査を1回通してから**変異を始めること。
