# N-7 データタブ My Data 改修 — 凍結仕様（2026/08/16 本人指示）

## 本人の指示（原文の要旨）

- HNR も重心も**音によってベースが高く出たり低く出たりする**。全部の平均の数値だけ出すのは違和感。
- My Data に**楽器種別の選択**を追加。**1ヶ月（期間セレクタ）の隣**。余計なカードにしない。
- 上部の `+1.2¢` `±3.4¢` などは**今のレイアウト含め維持**。
- その下に**折れ線グラフ**を追加。縦軸は 0¢ からの乖離（**真ん中が ±0¢**）、横軸は**選択されている
  楽器の最高音から最低音まで全部**（今の平均差分カードをタップしたときのグラフと同じ軸）。
- 線は**2本**: ①選択中の期間・楽器種別で抽出した平均差分 ②**今日**の平均差分。
- **HNR・重心・音量も同様に2本の折れ線**を追加。
- 配置は**案D**（`design/data-tab-proposals-2.html`）の横棒をこの折れ線に置き換えたイメージ。
- ピッチの折れ線だけは `+1.2¢` `±3.4¢` `Great` のテキストが残るので**別扱い**。
  その別扱いの表現は**カードでもよい**（本人が委任）。

## 凍結する形（正典 = `design/data-tab-final.html`）

1. **楽器種別セレクタ**: ヒーロー右上を `Alto ▾ · 1ヶ月 ▾` の並びにする（どちらも素テキスト+▾、
   F-72 の作法。タップで既存の DataOptionSheet 型のシート）。語彙は計測タブの saxType と同一。
   **既定値 = 計測タブで選択中の saxType**。
2. **セレクタの効く範囲** = ヒーローの数字・4本の折れ線。**セッション一覧には効かせない**
   （一覧には既存の絞り込みピルがある。二重の絞りは混乱のもと）。
3. **セッションの楽器種別** = `s.saxType ?? 現在のsaxType`（LatestSessionCard 等の既存の
   フォールバック規則をそのまま使う。新しい規則を発明しない）。
4. **ヒーロー**: 数字・評価ピル・副次行・スパークラインは**現状維持**（「今のレイアウト含め維持」）。
   データは期間+楽器種別で抽出したものに変わる。
5. **ピッチの折れ線**（別扱い）: ヒーローの直下・ヒーローと同じカード扱いでよい（本人委任 → カードに
   する）。NoteAxisLineChart の軸（音名 × ¢、0 が中央、0 の線は破線）。線2本:
   期間平均（薄い `--c-accent-line` 系）と今日（濃い `--c-accent`）。
   **N-6 で入れた「ヒーローの数字タップで開閉」は廃止**（常時表示になるため）。
   検査 26.2 の該当ブロックは本人指示による仕様変更として書き換える（黙って消さない）。
6. **HNR・重心・音量の折れ線**: 案D の行構成（指標名 + 右に今日の値と期間平均との差、下に折れ線）。
   枠なし・カードなし・行間は細い罫。縦軸はその指標の値域（ピッチと違い 0 中央の縛りは無い）。
7. **置き換え**: 累計/最新の2行（MetricRow）・数字タップの音名グラフは、この4本の常時表示の
   折れ線が引き継ぐ。**情報は失わない**: 累計は期間セレクタの「全期間」で出せる。
   最新（直近1回）の数字は行ヘッダの「今日」の値が引き継ぐ。
8. **今日のデータが無いとき**: 今日の線を描かず、期間平均の1本だけ。行ヘッダは「今日 —」。
9. **機能を1つも落とさない**（本人の恒久指示）: 期間セレクタ9種 / セッション一覧 / 絞り込みピル /
   アップロード+進捗通知 / 「…」の削除・一括リード変更 / 目安（あれば破線を重ねる）は全部そのまま。

## 実装上の注意

- NoteAxisLineChart は複数系列（`series` 配列）を既に受ける。SERIES_STYLES を使い、
  新しい色を発明しない。
- 音ごとの平均は computeNoteAverages 系の既存導出を使う（HNR/重心/音量の per-note は
  理想値プロファイル生成と同じ土台）。
- 変えた検査・消した検査は、すべて「本人指示（N-7）」を理由として明記する。
- 変異試験は単独逐次（F-94）。
