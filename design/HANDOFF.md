## 環境まわりの注意（この環境で実際に踏むもの）

1. **`node_modules` はコンテナに残らない。** 何をするにもまず `npm install`
2. **`速度(60fps耐性)` / `音色測定の速度(60fps耐性)` の2件はマシン負荷で落ちる。**
   検証ゲートは他の重い処理と並走させない
3. **Browser pane は `document.hidden=true` で `requestAnimationFrame` が1度も発火しない**。
   判定は inline style で行う。`resize_window` で **375×812** にしてから測る
   （既定だと環が 0px に潰れて測定を誤る）
4. **HMR 失敗で古いコードを測る事故がある。** 測る前に served コードに自分の変更の綴りがあるか確認する
5. **変異試験は単独逐次**（並列は速度検査が偽 KILL を生む）。複製ツリーで行い、実ツリーには当てない
6. **IndexedDB はキー単位で復元。`clear()` / `deleteDatabase` 禁止**
