- 「選択」が何の選択か分からない → **リードをまとめて変更の機能を削除**し、**選択＝削除だけ**に
- **取り込みが目立たない** → リードタブの浮かせる案を採用
- 採用: **P案。ただしカードの色だけR案の灰**

## N-11 確定仕様

1. **上部の空白を解消**: `Alto ▾ · 1ヶ月 ▾` を「My Data / 分析」と**同じ行の右端**へ
   （`margin-left: auto`）。独立した帯を作らない。セレクタの当たり判定は §5 の 44px を維持。
2. **蓄積量の3数字はそのまま**（回数 / 総演奏時間 / 計測した音）。
3. **グラフカード**:
   - 地は**灰**。**新しい値を発明せず既存トークン `--c-sunken`（#EEF1F4）**を使う
     （案Rの #F1F3F6 は正典上の見本値。実装は体系内の最も近い段に寄せる）。
     角丸は付けない（左右いっぱいに伸ばすため）。
   - **左右の余白を食い破って画面いっぱい**（`margin: 0 calc(-1 * <本文の左右余白>)`）。
     本文の左右余白の値は既存の1箇所から取り、**数値を写さない**。
   - **カード内に4指標のタブ**（平均差分 / HNR / 重心 / 音量）。等幅で横並び、
     選択中は白地のピル。`aria-pressed` は常に1つだけ true。
   - **数字は選択中の指標の1つだけ**（タブの下に大きく）。他3指標の数字は出さない。
   - 凡例（期間平均 / 直近日）はカード内・数字の右。
4. **Y軸のラベルをプロットに重ねる**: 左に軸用の余白を取らず、目盛の文字を
   プロット領域の左上に重ねて描く。**線の描画幅が実測で広がること**を数値で示すこと。
5. **My Data のグラフだけフラジオを含めない**: 横軸は各楽器の**通常の音域まで**
   （F-103 で足した `highMidi + 4` を**この画面のグラフだけ**含めない）。
   **他の画面（リード比較・個体詳細・セッション詳細・PIVOT・計測）は含めたまま**。
   → 音域の上限は引数で切り替える（グローバルに変えない）。両方向を検査で固定。
6. **「選択」は削除だけ**: **一括リード変更の機能を削除**（本人の明示指示。
   落としてよい唯一の機能）。選択モードに入ったら「n件を削除」と「キャンセル」だけ。
   関連する state・部品・検査も削除し、読み手ゼロの定義を残さない。
7. **取り込みは浮かせるボタン**（下記の共通部品）。一覧見出しの「↥ 取り込み」は撤去。

## F-111 リードタブの追加ボタン（案D）

- `＋ リードを追加` を**右下に浮かせる**。一覧末尾の「＋ 追加」は撤去。

## 共通部品「浮かせるボタン」（両画面で同じ1つ）

- 高さ 44（§5）/ 角丸 `--r-pill` / 地 `--c-accent` / 文字 `--c-on-accent` / 影あり
- 位置: 右端は本文の左右余白と揃える。下端は
  `calc(var(--nav-h) + env(safe-area-inset-bottom) + <既存の余白トークン>)`。
  **直書きの数値を作らない**。
- **一覧の下に、ボタンの高さぶんの余白を確保**して最下行に重ならないこと（実測で示す）
- `aria-label` を持つ。スクロールで動かない。

ばらつきの帯 / 4指標すべてのグラフ。
**削除してよいのは一括リード変更だけ**（本人の明示指示）。
