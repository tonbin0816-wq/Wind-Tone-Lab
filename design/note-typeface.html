Ficus / 演奏中サーフェス — 音名の書体

「適切な横幅」を、その場で決めてください。

ご指摘のとおり現状は書体既定の幅そのままです。Instrument Serif には可変軸が無いため、幅を指示できません。 そこで幅軸（wdth）を持つ書体を2つ用意しました。下のスライダーで幅を動かし、 実寸の環の中で見比べて決めてください。決めた値がそのまま実装の指定値になります。

先に制約をお伝えします。 可変フォントは2つとも、Instrument Serif ほど細くできません（実測：Instrument Serif 0.457em に対し、 Roboto Serif は最細 wdth 50 でも 0.588em、Playfair は最細 wdth 87.5 で 0.565em）。 「半角感は正しい」というご指摘を優先するなら、現状の細さを保ったまま横幅を数値で指示できるのは第2案（scaleX）だけです。 幅の指示を優先して少し太くなるのを許容するなら第3・第4案になります。
調査中に別の不具合が見つかりました。 音名は ♯(U+266F) と ♭(U+266D) という本物の音楽記号を使っていますが、 Instrument Serif にはこの2文字が収録されていません（実測：どちらも幅ちょうど 1em ＝ グリフ不在時の値）。 つまり現在の B♭ は「B＝細身の欧文書体」＋「♭＝別書体の全角幅」という継ぎ接ぎで表示されています。 このページの ♯ / ♭ はすべてSVGで描いています。どの書体を選んでも、太さと幅が本体と揃うようにするためです。

選んだあとに起きること

決定した書体と wdth 値を design/DESIGN-SYSTEM.md §4.3 に固定し、以降のループはその値だけを参照します。

1. 書体と幅の確定 — 選ばれた書体を --font-serif に据え、font-variation-settings: 'wdth' N を指定値として明記します。可変フォントなので、幅は数値として指示された状態になります。

2. ♯ / ♭ のSVG化 — 書体に依存しないSVGコンポーネントにします。音名の文字サイズに追随し、太さも揃います。リード番号（--font-serif のもう一つの用途）は数字のみなので影響を受けません。

3. 読み込みの是正 — 現在フォントの @import は React が描画する <style> の中にあり、JSバンドル評価後に読み込みが始まります。演奏中サーフェスの主役が最も遅い経路で読まれている状態なので、index.html に移します（バックログ P2-1）。

4. サブセット化 — 音名に必要なのは A-G と数字だけです。全文字を読む必要はありません（このページでは 147KB → 35KB になりました）。
