**2026/08/25 本人指示。** 出どころは本人が Claude Design キャンバス上で直接いじった
`design/canvas/Main.dc.html`（平均差分 × 折れ線）と `design/canvas/Windows.dc.html`
（平均差分 × 窓型）。**この2枚が正典**で、generate.mjs は既定で上書きしない。

本人の言葉:
> 8/24×my平均のように2本の数値を選択可能にして、グラフを一つに固定しています
> min高さが44に設定されていましたが、この行で44は余白が大きすぎるのでここは最小44の必要はありません
> 凡例は消してチップの枠をその該当の折れ線と同じ色にして
> 左右で同じものを選べないように、一方で選ばれているものはそもそももう一方の選択肢から削除するようにして

## 1. チップの行は「式」になる

比較対象を**1つ選ぶ**形（自分の平均 / 目安 / ±0 の3択）をやめ、
**2つの系列をそれぞれ選ぶ**形にする。

```
折れ線   [ 8/24 ] ×  [ my平均 ]      ← 2本を重ねる
窓型     [ my平均 ] ー [ ±0 ]         ← 引き算
```

- **記号の使い分けは意図的**（本人確認済み）。`×` = 2本を重ねる / `ー` = 引き算
- 系列の候補は **その日 / 期間平均 / 目安 / ±0** の4つ
- **一方で選ばれている系列は、もう一方の選択肢から消す**（本人指示）。
  「押せない選択肢を出さない」という既存の規則（F-77）と同じ手なので、
  `myDataCompareTargets` のフィルタに条件を1つ足す形で収まる
- 「自分の平均」→ **「my平均」**

## 2. 凡例を撤去し、チップの枠が系列の色を持つ

本人指示「凡例は消してチップの枠をその該当の折れ線と同じ色にして」。

- D-8 で足した凡例（`legend`）は**撤去**する
- チップの枠は `SERIES_STYLES` から引く。**綴りを2箇所に持たない**
  （D-8 で凡例に課したのと同じ規則。線と食い違いようがない形にする）
- 選択中/非選択の区別は枠の色では返せなくなる（枠が系列色になるため）。
  **チップは常に「いま選ばれている系列」を表示するので、非選択の状態が無い**
  ── 押すと選択肢のシートが開く（既存の `DataOptionSheet`）

## 3. §5(44pt) の例外

本人指示「この行で44は余白が大きすぎるのでここは最小44の必要はありません」。

- チップの高さは **20px**（行の高さ 52 → 35px）
- **`DESIGN-SYSTEM.md` §5 に例外を明文化する。** いまの §5 は無条件で 44pt を要求しており、
  書かないと次に触る人がまた 44 に戻す
- 当たり判定は見た目と別に広げられる（`SubTabs` が横方向でやっている手）。
  **縦は行の高さいっぱい、横はチップの幅**まで。44 は要求しない

## 4. グラフは1つに固定

- **窓型のマトリクスは1枚。** 「今日の自分」を消し、選んだ2つの引き算だけを描く
- `showLower` は役目を失う（「比較対象 = 自分の平均のとき下の枚が構造的に全部0」の判定は、
  §1 の「左右で同じものを選べない」が**構造的に**引き受ける）
- `NoteMatrixBlock` の `title`（今日の自分 / いつもの自分）と `sub`（"8/24 − ±0"）は
  **式がチップ行に出るので重複**する。両方撤去する

## 5. 折れ線の「合っている」帯は出さない

**本人確認済みで意図的。** 窓型の灰（`--c-quiet`）は**残す**。

> 人間の感覚的に食い違いません

D-7b（帯の濃さ 0.28 を実機で見ていない）は、帯そのものが無くなるので**起票ごと閉じる**。

## 6. 読み手ゼロになるもの（定義ごと落とす）

- `refByIdx` / `refLabel` … D-8 で足した「比較対象を破線で重ねる」受け口。
  比較対象が2本目の線そのものになるので役目が消える
- `bandAbs` … 折れ線の帯（§5 で撤去）
- `legend` … §2 で撤去
- `MY_DATA_COMPARE_TARGETS` / `myDataCompareDefault` / `myDataCompareFallback` …
  「1つ選ぶ」前提の3つ。2つぶんの既定と、選択肢から消す規則に作り替える

## 8. 中央線（D-9u の裁定 2026/08/25）

本人指示「平均差分以外はその項目の平均を中央線にして同様に」。

**中央線は必ず1本ある。** 上下の目盛線を消しても基準が消えないのはこれのため。

| 指標 | 中央線 | 縦のドメイン |
|---|---|---|
| 平均差分（¢） | **0** | `lo = -maxAbs` / `hi = +maxAbs`（従来の `zeroCentered`） |
| HNR / 重心 / 音量 | **その指標で描いている全値の平均**（スカラー1つ） | `lo = 平均 - maxDev` / `hi = 平均 + maxDev` |

「同様に」＝ **中央線をまん中に置いて上下対称のドメインにする**、と解釈した。
こうすると 0 中心と平均中心が同じ形になり、目盛は必ず `hi / 中央線 / lo` の3つで、
**中央線が絵の中央に来る**（重心のダミーで中央線 1577Hz、目盛 2515 / 1577 / 640）。

線の色は従来の 0 線と同じ `--c-line-strong`。上下の目盛線（`--c-line`）は**引かない**。

## 11. 分析（PIVOT）タブの上部（D-9r 案R）

集計範囲セレクタが子タブ行から抜けたあとの空きに、**表題「PIVOT」を移す**。

```
現状   [My Data] [分析]                      ← 右端が空く
       PIVOT                                 ← 15px / --c-accent / 700
       条件・縦軸・横軸…（説明）
案R    [My Data] [分析] ……………… PIVOT       ← 12px / --c-accent / 700
       条件・縦軸・横軸…（説明）
```

- 文字組み **15px → 12px**。色と太さ（`--c-accent` / 700）はそのまま。
  12px は集計範囲セレクタと同じ段なので、**右端の作法をそのまま引き継ぐ**
- **見出しは「分析」1つだけ**になる。表題の行（15px + 余白4）が丸ごと消えて **19px 縮む**
- F-99 の意図「PIVOT の文字があれば Excel も想起できる」は**名前が残るので保たれる**
