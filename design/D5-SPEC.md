## 1. マトリクス（案B1）

**正典 `#9b` の色による発散スケールを廃止する。** 本人の指摘「色だとどちらが高い/低いか
想像しづらく、グラデーションではどれくらい高いかの程度が読みにくい」。

- 窓 **22.2 × 28px** / 角丸 `--r-xs` / gap 3px / 地 `--c-sunk`（値がある窓だけ）
- **段ごとに 0 の線を1本**：行の左端から右端まで、窓の枠と隙間を貫いて通す（`--c-line-strong`）。
  窓ごとの短い線ではない
- **棒**：幅9px・中央・角丸1.5px。窓の中央（14px）から上下へ。最大 12px。
  **上＝高い `--c-above`（金）/ 下＝低い `--c-below`（紺）**
- **数値**：棒と**反対側の半分**（高さ50%の枠に中央揃え）。棒は片側にしか伸びないので**絶対に重ならない**。
  9.5px / `--font-num` / `--c-ink-2`
- **行はオクターブの降順**（5 → 4 → 3。上の行から高い音）
- 8段の凡例は**廃止**。代わりに1行の説明（「段の中央が0。上＝高い / 下＝低い」）

### 1.1 色トークン
`--c-div-1`〜`--c-div-8` は**削除**し、機能色を2つに置き換える。

```
--c-above: #B5891C;   /* 比較対象より高い */
--c-below: #174585;   /* 比較対象より低い。--c-accent と同値だが意味が別 */
```
`--c-danger` と `--c-bad` が同値でも別トークンなのと同じ扱い（意味を混ぜない）。

### 1.2 実測（モックで確認済み）
窓の内幅 **22.00px**。9.5px での送り幅は `+6` 11.63 / `-162` 19.17 / `+166` **21.88** / `-1234` 24.30px。
**3桁までは入る**（余裕 0.12px）。4桁は窓が切る — **棒と色は切れない**ので高低の信号は残る。

## 2. カレンダー（月表示・案G）

- 見出し `2026年8月` ＋ サブに `合計時間 · 練習日数`、右に前月 `‹` / 翌月 `›`
- 曜日は**日曜始まり**（参考画像の一般的な暦に合わせる。5週窓の月曜始まりから変更）
- マスは 38px。**練習した日だけ日付を丸（28px）で囲む**。丸の濃さは練習量4段
  （`--c-accent-tint` → `--c-accent-line` → `--c-accent-mid` → `--c-accent`）
- 選択日は丸の外側に `box-shadow: 0 0 0 2px var(--c-ink)`
- 月をまたぐと選択日は**その月の記録のある最新の日**へ。無ければ選択なし（一覧は空の文言）
- 母集団は今までどおり（奏者=自分 ＋ 選択中の楽器種別）
- 暦日は `localDayKey` だけで組み立てる（罠14）

## 3. 上部の並び（決定7）

```
子タブ行  My Data / 分析          Alto ▾ · 期間 ▾
┌ カード ────────────────────────────┐
│ 平均差分  HNR  重心  音量            ← 指標タブ
│ 比較対象  [自分の平均] [±0]          ← 比較対象チップ
│ 今日の自分            −6 〜 +6      │
│ （マトリクス）                       │
│ ─────────────────────────────────  │
│ いつもの自分          −4 〜 +5      │ ← 比較対象が「自分の平均」以外のときだけ
│ （マトリクス）                       │
│ 段の中央が0。上＝高い / 下＝低い      │
└──────────────────────────────────┘
```
**マトリクス2枚を1枚のカードにまとめる。** タブと比較対象がカードの中の全部を支配するので、
「タブがどこまで効くか」が箱で示される（正典は2枚のカードに分けていたが、
そのままだとタブが外にあるカードまで支配することになり、指摘の「2種類のタブが同じ見た目」が残る）。

## 4. セッション詳細 / リード詳細

### 4.1 セリフ廃止
`--font-serif` を使っていた3箇所（`MetricTabCard` の大きな数字 / `ReedScoreField` の3カラム /
`DetailHeader` の見出し）をすべて `--font-num` へ。
大きな数字は `--fs-hero`(46) のまま、評価と見出しは `--fs-2xl`(28) のまま（**字送りだけが変わる**）。

### 4.2 タイムラインの固定
`timelineMetric` / `referenceBasis` / `referenceSessionId` とその選択UIを削除。
`getComparisonTarget` は `getNoteIdeal(selectedIdeal, frame.semitoneIndex)` だけになる。

**残るもの**：ドリルダウンの「ピッチ一致度」（絶対値基準）と「音色一致度」（目安基準）は
**どちらも従来どおり動く**（音色の比較対象は目安なので、基準セレクタとは無関係だった）。
**消えるもの**：目安基準の色分け / 別セッション整列 / 音量・重心・HNR の時間変化。

### 4.3 メモ
ラベル `メモ`（10.5px / `--c-ink-3`）を上、その下に `<textarea>` が全幅・左詰め。
`rows=1` から入力量に追従して伸びる（`scrollHeight` で自動調整）。改行有効。
確定は従来どおり blur。**セッション詳細とリード詳細で同じ形**。

### 4.4 音階ごとの平均
表ごと削除。`noteGroups` の読み手が無くなるので、そちらも落とす。

### 4.5 編集シート
行は `min-height: var(--tap-min)` ＋ 下罫。
**ラベル 12px `--c-ink-3` 左 / 値 13px `--c-ink` 左**（値の左端は `3em` で縦に揃える）。
`PerformerSelector bare` と `PlainSelect` は親から 13px を継承させる（行に `fontSize` を敷く）。

## 5. リード比較タブ（決定6）

4枚のグラフ（`REED_COMPARE_CHART_KEYS`）を**指標タブ＋グラフ1枚**へ。
- 並びは `DETAIL_CARD_METRICS`（平均差分 → HNR → 重心 → 音量）。**4画面で同じ並びになる**
- 部品は `MetricUnderlineTabs`（他3画面と共有）
- **大きな数字は出さない**（リードが複数なので1つに決まらない）。値は凡例と折れ線が示す
- `REED_COMPARE_CHART_KEYS` は読み手が無くなるので削除

## 6. 一覧と削除（決定10・11）

- 「すべてのセッション」から**期間の絞り込みを削除**（`sessionFilterDateFrom/To` / date 入力2つ /
  期間ピル / `dateFilterText`）。**日付で絞る手段は PIVOT の「録音日」に残る**
- 削除の一手（モード中）を**ゴミ箱アイコン＋件数**へ：
  - すべてのセッション（`n件を削除`）
  - リードタブの箱（`n箱を削除`）と個体（`n枚を削除`）
  - **番号変更の「完了」はそのまま**（削除ではない）
- 塗りの規則は不変：**選択0件では塗らない**（`.ctl-danger[data-armed]`）。
  アイコンは `Trash2`、件数はその右に数字

## 7. PIVOT（決定12・13・14）

- 名前：`並べる軸`→**縦軸** / `数値`→**横軸** / `分け方`→**分析軸**。
  1行の説明（F-99）の語も揃える
- 「＋」を押すと **`DataOptionSheet` で12次元から選ばせる**。選んだ次元でフィルタを1つ足し、
  編集を開く（今は必ず「音名」が足され、変更は開いた編集の中でしか出来ないので
  **追加できるのが音名だけに見えていた**）
- 3カラムの縦幅：`PlainSelect` に `caption` を足し、**小さいラベルも同じ `<label>` の中**へ入れる。
  セル全体が1つの 44pt の当たり判定になり、カードは 88px → **76px**
