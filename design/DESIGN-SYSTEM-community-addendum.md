## 追記 1 ─ §1.5 と §1.7 の間へ（順位の色）

```markdown
### 1.5a 順位の色（2026/08/28。コミュニティタブの追加に伴う）

**順位を表す色は紺の明度段階では代用できない。** 1位・2位・3位に序列があることを
色で示す必要があり、これはパレットに無い第3の色系統になる。

| トークン | 値 | 用途 |
|---|---|---|
| `--c-rank-1` | `#C79A3E` | 1位。アイコンの環と順位の数字 |
| `--c-rank-2` | `#9BA6B4` | 2位。同上 |
| `--c-rank-3` | `#A9743E` | 3位。同上 |

**厳守事項**
- **順位以外に使わない。** 系列識別（§1.7）にも機能色（§1.5）にも流用しない
- 使ってよいのは**アイコンの環の線と、順位の数字の文字色**の2つだけ。面を塗らない
- 4位以下には色を与えない（`--c-ink-3` の数字のまま）。色が付くのは3つまで
- 金属質の光沢・グラデーションは使わない。単色で足りる

> 王冠やメダルの**絵文字は使わない**。端末ごとに絵柄が変わるため、iPhone と Android で
> 同じ画面が別物に見える。順位は環の色と数字の色だけで示す。
```

## 追記 2 ─ §1.6 の後へ（アイコンの背景色）

```markdown
### 1.6a アイコンの背景色（2026/08/28。コミュニティタブの追加に伴う）

利用者が自分のアイコンを選べるようにするため、**絵柄 × 背景色**の組み合わせを用意する。
アプリの色は紺一系統なので、ここで10色の第4の色系統が要る。

| トークン | 値 | | トークン | 値 |
|---|---|---|---|---|
| `--c-avatar-1` | `#174585` | | `--c-avatar-6` | `#A8543C` |
| `--c-avatar-2` | `#3E6E8E` | | `--c-avatar-7` | `#7D4A6B` |
| `--c-avatar-3` | `#2F6F5E` | | `--c-avatar-8` | `#5B5FA3` |
| `--c-avatar-4` | `#6B7A3F` | | `--c-avatar-9` | `#4A5567` |
| `--c-avatar-5` | `#9A6B2F` | | `--c-avatar-10` | `#2C3542` |

**厳守事項**
- **アイコンの円の塗り以外に使わない。** 系列識別にも機能色にも流用しない
- **全て彩度を落としてある。** 機能色（`--c-good` `#16A34A` / `--c-warn` `#D97706` /
  `--c-bad` `#DC2626`）と見分けが付かなくなるのを避けるため。緑系は `#2F6F5E`、
  橙系は `#9A6B2F`、赤系は `#A8543C` で、いずれも機能色より暗く鈍い
- 白抜きのアイコンが乗るので、**明度は10色とも白に対して 4.5:1 以上**を保つこと。
  色を足すときもこの下限を満たす値にする

実測（対 `#FFFFFF`。2026-08-28 確認）:

| 色 | 比 | 色 | 比 |
|---|---|---|---|
| `#174585` | 9.43 | `#A8543C` | 5.25 |
| `#3E6E8E` | 5.49 | `#7D4A6B` | 6.85 |
| `#2F6F5E` | 5.91 | `#5B5FA3` | 5.82 |
| `#6B7A3F` | 4.69 | `#4A5567` | 7.54 |
| `#9A6B2F` | 4.65 | `#2C3542` | 12.39 |

最も余裕が無いのは `#9A6B2F`（4.65）と `#6B7A3F`（4.69）。**この2色は明るくしないこと。**

> 絵柄は Phosphor Icons の fill ウェイト（MIT・商用利用可）24種。SVG スプライトとして
> 同梱し、実行時に外部から読み込まない。一覧は `design/community-tab-proposals.html` の 06 節。
```
