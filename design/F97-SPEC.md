# F-97〜F-104 実機フィードバック第3陣 — 凍結仕様（2026/08/17 本人指示）

## F-97 削除モード: 先頭行のチェックボックスが無く、タップすると日付に重なる【最優先】

本人のスクリーンショット2枚（iPhone 実機）による症状:
- 「セッションを選んで削除」に入ると、**先頭行だけチェックボックスが表示されない**
  （2行目以降は正常: チェックボックス+字下げされたテキスト）
- その状態で先頭行をタップすると選択は効くが、**チェックが日付テキストの上に重なって描かれる**
  （先頭行のテキストは字下げされないまま）
- 「まとめて変更を押すと崩れる」ほう（F-85）は**直ったと本人確認済み**

注意:
- **症状から当たりを付けて書き換えない。** 実 DOM で先頭行と2行目の構造・スタイルの差を実測して
  原因を特定してから直すこと（このプロジェクトの鉄則）。
- 本人のスクリーンショットのグラフには目安の凡例が写っており、**撮影時の端末は N-8 より前の
  ビルドだった可能性がある**。まず現行ビルドで再現を試み、現行コードで構造的に起こり得ないなら
  その根拠を示すこと（その場合はキャッシュ由来の可能性を報告）。
- 直したら、削除モードで**全行**にチェックボックスが出る/字下げされることを検査で固定。

## F-98 セッション詳細の残り（本人: 「全然ダメ」）

1. **色付きの枠を撤去**: 日付（datetime-local）・メモ（textarea）などの入力欄が地色付きの
   箱（--c-sunken 系）で描かれている。**セッション詳細内の入力欄は白地+細い下線（罫）の作法**へ
   （値の文字はそのまま。ネイティブ input の中身は不変）。
2. **奏者・リード・楽器の情報が「ただのテキスト羅列」**: ラベル+値の行構成（.mname 12px /
   値 .mnums 系）に整形。1行1情報で揃える。
3. **タイムラインと音階ごとの平均に付いている長い解説文を削除**（本人が名指し）。
   機能のラベル・状態表示（「★ 目安設定中」等）は消さない。

## F-101 期間セレクタが一瞬「1ヶ月」に戻るフリッカ

タブ切替のたび `usePersistedState` が既定値で初期化され、IndexedDB の読み込みまで
既定表示が見える（F-93 と同根）。**モジュールスコープのキャッシュ**を `usePersistedState` に
足す: 一度読めた値は Map に保持し、再マウント時は `cache.get(key) ?? 既定値` で初期化。
初回起動の挙動は不変。**これで F-93（リード0件の一瞬表示）も同時に解消**するので、
両方を実測で確認して F-93 も消し込むこと。

## F-102 リード番号の編集の入口を「…」へ

- リードタブの「…」に**「リード番号を変更」**を追加
- リード個別ページの**番号の下の点線（編集可の下線）を削除**。編集機能そのものは維持
  （「…」からの経路で番号編集に到達できること）

## F-103 フラジオ対応: 計測範囲を最高音+長3度まで拡張

各楽器の運指表・音名軸・チューナー判定の**上限を、通常の最高音から長3度（+4半音）上まで**拡張。
下限は不変。音名軸グラフの横軸にも反映（軸が伸びるぶん、既存検査の期待値を N 番の理由付きで更新）。

## F-104 音が沢山変わる間のメトロノームのフレームレート低下

本人実機報告。**原因をプロファイルで特定してから直す**こと（推測での書き換え禁止）。
候補: 音の変わり目の処理（音色計測 8192点FFT の間引きタイミング / ノート切替の集計）が
rAF を奪っている等。計測の正確さを落とす直し方は不可（間引き・スケジューリングで解く）。
直後に「速度(60fps耐性)」系の検査が実挙動を映しているかも確認。
