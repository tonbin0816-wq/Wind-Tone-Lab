# N-8 データタブ: ヒーローのグラフ差し替え — 凍結仕様（2026/08/16 本人指示）

## 本人の指示（原文）

```
濃い青のカードの折れ線グラフを音ごとの平均サブの折れ線グラフに変更
それに伴い単独である音ごとの平均をグラフごと削除
目安は表示不要で、対象期間の平均と今日の平均だけでok
当日のデータがまだない場合は直近の記録のある日の平均を表示
```

## 凍結する形

1. **ヒーロー（紺のカード）内のスパークライン（時系列）を廃止**し、同じ場所に
   **音名軸の折れ線2本**（期間平均・今日）を描く。軸は N-7 のピッチカードと同じ
   （横=選択中の楽器の全音域、縦=0¢中央、0の線は破線）。
2. **紺地の上なので色はヒーローの既存配色だけを使う**（新色を発明しない）:
   期間平均 = `#B9C9E4`（旧スパークラインの線色）/ 今日 = `#FFFFFF` /
   0の破線 = `#3D5F94`（旧スパークラインの基準線色）/ 軸ラベル = `#9DB3D6`。
   軸の目盛・音名ラベルは**最小限**（要素を減らす方針。詳細は実装役が実測で判断し報告）。
3. **N-7 で作ったピッチカード（.pitchcard）はグラフごと削除**。
4. **目安（selectedIdeal）の破線と Δ を My Data の全グラフから外す**
   （ヒーローの折れ線 + HNR/重心/音量の3行）。表示するのは期間平均と今日の2本だけ。
   **他画面（リード詳細・セッション詳細）の目安表示はそのまま**（触らない）。
5. **今日のデータが無い場合は「直近の記録のある日」で代替**する:
   - 対象 = 奏者「自分」+ 選択中の楽器種別のセッションのうち、最新の `recordedAt` の**暦日**の全フレーム
   - ヒーローの数字・折れ線の濃い線・3行のヘッダ「今日 …」のすべてに同じ規則を適用
   - **ラベルは「今日」と偽らず、その日付を出す**（例: `8/15`。凡例・行ヘッダとも）
   - 記録が1件も無ければ従来どおりの空表示
6. 機能を落とさない: 期間セレクタ9種 / 楽器セレクタ / 一覧 / 絞り込み / アップロード / 「…」。
   数字・評価ピル・副次行（±/平均）のレイアウトは維持。

## 検査の扱い

- スパークライン・ピッチカード・目安Δ（My Data 側）を固定していた検査は
  **本人指示（N-8）を理由に明記して書き換える**（黙って消さない）。
- 直近日フォールバックは純関数に出し（例: `myDataTodayOrLatestFrames`）、
  「今日あり／無し＋直近あり／全く無し」の3状態を実行で検査する。
  **描画側がその関数の戻り値とラベルを使うこと**（配線）まで固定する
  — 「純関数は完璧・配線が無防備」で通算17回差し戻されている。
