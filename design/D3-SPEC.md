# D-3 / D-4 凍結仕様 — セッション詳細を `#14b` へ、リード個体詳細を `#15a` へ

**正典**: `design/dc-mydata-redesign.html` の **`#14b`**（セッション詳細）と **`#15a`**（リード詳細）／
同梱 README の "Screen 3" / "Screen 4"。

**上位規則（D-1 と同じ・本人の裁定 2026/08/22）**
1. レイアウト・構造・余白の**関係**は正典から採り、**色/フォント/文字サイズはトークンへ写像**する。
2. **セッション詳細（`#14b`）の録音カードは「再生なし」で作る**（本人の裁定）。
   音声そのものを保存していないため（マイクもアップロードも解析してフレームだけ残す）。

**正典の芯**: 「2画面を行き来しても読み方が変わらないよう、**同じ部品・同じ順番**にする」。
したがって指標のカードは**1つの部品**（`MetricTabCard`）にして両方から呼ぶ。

## 1. 新しく足した共通部品

| 部品 | 役目 |
|---|---|
| `DetailHeader` | 戻る導線 ＋ 右上の一手 ＋ セリフの見出し（＋添え字）＋ **1行メタ**。`#14b` / `#15a` が同じ形を持つので部品にした。区切りの「·」は**ここ1箇所**が描く |
| `MetricTabCard` | 指標タブ4つ → 大きな数字（セリフ）＋単位、右に補足 → **常時表示**の音名軸グラフ。指標の状態は**呼び出し側が持つ**（セッション詳細では下の表の列も同じ指標に追従するため） |
| `MetricUnderlineTabs` | 指標の下線タブ。**My Data（D-1）とも共有**。見た目の間隔は `halfGap × 2`、当たり判定は行の gap を 0 にして padding で作る。下線は**文字の幅**に付く（ボタン全体に付けると隣と繋がる） |
| `BottomSheet` | 下端から出るシートの**枠**（暗幕・角丸28・つまみ36×4・影・下スワイプ・Escape・上限）。N-6 の `DataOptionSheet` が持っていた枠を外に出しただけで、値は1つも変えていない |
| `SessionEditSheet` | セッションの属性（日付・奏者・リード）を直すシート |

**文字サイズの写像**: 正典の 42px（大きな数字）→ `--fs-hero`(46) ／ 30px（評価）→ `--fs-2xl`(28) ／
27px（見出し）→ `--fs-2xl`(28) ／ 13.5px（タブ）→ `--fs-sm`(13)。
体系の7段に無い値は**いちばん近い段へ寄せる**（新しい文字サイズを発明しない）。

## 2. セッション詳細（`#14b`）

並び: ヘッダー → 指標グラフカード → 録音カード → メモカード → 音階ごとの平均。

- **ヘッダー**: `‹ 一覧` ／ 右に `★ 目安に設定` と `編集` ／ 見出し `8月22日`（セリフ）＋ 時刻 ／
  1行メタ `自分 · Alto · 未紐付け · 0:24`（**読み取り専用**）
- **編集シート**: 日付（`datetime-local`）・奏者（`PerformerSelector bare`）・リード（`PlainSelect`）。
  **N-9 の5行から1つも減っていない**（楽器は元から読み取り専用、メモは独立したカード）
- **指標グラフカード**: `MetricTabCard`。目安（`selectedIdeal` / `METRIC_IDEAL_KEYS`）は**残す**
  （N-8 で消したのは My Data 側だけ。検査 28.4）
- **録音カード**: `PhraseTimeline` をカードで包み、見出し `録音` を足す。
  「検出ノート n ・ 平均アタック xxx ms」は `PhraseTimeline` の中が既に出している
  （正典 `#14b` の「検出 4音 · 平均アタック 164ms」と同じ内容。綴りを2箇所に持たない）
- **メモカード**: 1行・`min-height: 44`・空なら「タップして入力」
- **音階ごとの平均**: **選んでいる指標の列だけ**出す（実音 / 指標 / 目安との差の3列）。
  正典の指摘「元の表は5列を無理に詰めて HNR が画面外に切れていました」への答え

### 却下されたもの（正典が名指し・再提案しない）
- 上部の「日付/奏者/リード/楽器/メモ」5行が全部同じ濃さで並ぶ形（F-98 の形）
- 数字タップでグラフが出る形（`TappableMetricCard`）→ 常時表示 ＋ タブ切替へ

### 正典と意図的に違えた1点 — **機能を残す**
正典は「表示：ピッチ」「基準：絶対値」の選択UIも却下しているが、
**基準の切替（絶対値 / 目安 / 別セッション整列）はタブと重複していない**
（タブは音名軸グラフの指標を切り替えるもの、こちらはタイムラインの比較基準）。
落とすと機能が消えるので `PhraseTimeline` の中身はそのまま残した。**BACKLOG に起票（D-3b）。**

## 3. リード個体詳細（`#15a`）

並び: ヘッダー → 評価カード → 指標グラフカード → 評価の推移カード → 浮かせるボタン「計測」。

- **ヘッダー**: `‹ 一覧` ／ 見出し `Vandoren-3`（セリフ）＋ `#1`（そのまま編集欄）／
  1行メタ `開封 2026/06/09 · 75日 · 4 セッション`（`reedDetailMetaParts`）
- **評価カード**: 3カラム（値はセリフ `--fs-2xl` / `--c-accent`、下にラベル）＋ メモ行。
  行のどこを押しても3列ダイヤルが1回で開く（§6.4）
- **指標グラフカード**: **セッション詳細と同じ `MetricTabCard`**
- **評価の推移カード**: 見出し `評価の推移` ＋ 右に `n 回の評価` ／ 3系列 ／ 凡例 ／
  注記 `厚さ・バランスは M/D の記録から`（`reedScoreLateStartLabel`。
  **線が途中から始まる理由**が読めないと「途切れている」と誤読されるので、
  厚さ・バランスが最初の記録より後から始まっているときだけ出す）
- **計測**: **下端固定のバーではなく浮かせるボタン**（`FloatingAction`）。
  My Data の「録音を取り込む」と同じ部品・同じ位置・同じ影

### 却下されたもの（正典が名指し・再提案しない）
- 評価を3行リスト＋5段階ドットで表示
- 数字タップでグラフ出現
- 下端固定の「このリードで計測」ボタン

### 正典と意図的に違えた2点
1. **ヘッダー右の「編集」を置かない。** 正典 `#15a` は置いているが、この画面で編集できるのは
   #番号（見出しの中で直接）・メモ（評価カードの中）・評価（3カラムのタップ）だけで、
   すべて画面の中に入口がある。**何も起きない入口を作らない**（F-77 の罠）。
2. **1行メタに楽器種別を出さない。** 正典は `Alto · 開封 6/10 · …` だが、
   **リードは楽器種別を持っていない**（起票 F-87 が未着手）。持っていない値を書かない。
