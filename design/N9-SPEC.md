# N-9 セッション詳細 + 分析(PIVOT) の北極星化 — 凍結仕様（2026/08/16 本人指示）

## 本人の指示（原文）

```
個別セッションないのページとPIVOTがまだ旧式デザインなのでいい感じにほかのページと統一して
これから出かけるのでなるべく要素を減らすという点も忘れずに修正しておいて
```

## 方針

見た目の文法は確立済みのものだけを使う（**新しい意匠を発明しない**）:
- 地は白・カードの枠線と地色の箱を廃止・群は細い罫（`--c-line` / `--c-rule`）で分ける
- 選択は素テキスト+▾（F-72 の作法）またはピル。破壊的・低頻度の操作は「…」の中
- 見出しの階層は subtabs / `.shead .t`(13px/600) / `.mname`(12px) / `.mnums`(11.5px) の既存段
- 44px の当たり判定（§5）は維持。**機能は1つも落とさない**（本人の恒久指示）

「要素を減らす」の具体（本人が過去に名指しした違和感に沿う）:
- **長い説明文の削除**: PIVOT の「集計対象抽出(フィルター)・縦軸・横軸・指標を組み合わせて、
  蓄積データをマトリクスで俯瞰します。…」の段落は**丸ごと削除**（本人: 「長いテキストは趣旨がずれてる」）
- 見出しの重複を削る（子タブ「分析」の中の「PIVOT」表題など、同じことを2度言う要素）
- 枠・地色の箱・影を消し、罫に置き換える

## セッション詳細

- **機能は全部残す**: 日時編集 / 目安に設定（対象2択+命名+同名マージ）/ 奏者変更 /
  リード紐付け変更 / メモ / フレーズタイムライン一式（指標4種・比較基準・別セッション整列・
  小節線・スクラブ・ドリルダウン）/ 平均指標カード / 音階ごとの平均テーブル / 戻るスワイプ
- カード地・枠線 → 白地+罫。select 類は見た目だけ既存の作法（枠なしの文字+▾）に寄せ、
  **中身のネイティブ select はそのまま**（iOS の実寸問題を新しく作らない）
- 平均指標は N-7 の行の文法（`.mname` + `.mnums`）に寄せてよい。ただし
  セッション詳細の目安Δは**残す**（N-8 で消すのは My Data 側だけ）

## 分析(PIVOT)

- **機能は全部残す**: 条件追加/削除 / 12次元 / 値チップ / 音域帯まとめ選択 / 日付・日数範囲 /
  既定フィルタ / 軸セレクタ3枚 / 測度7種 / 折れ線 / 設定のタブまたぎ保持
- 説明段落と重複表題を削除。チップ・軸セレクタの枠と地色の箱を罫+ピルの文法へ
- 軸の説明文（現在の長文）は**1行以内**に圧縮するか削除

## 検査の扱い

- 旧デザインを固定していた検査は**本人指示（N-9）を理由に明記して**書き換える
- 触ってよいのはセッション詳細と分析(PIVOT)子タブの描画と、その検査だけ。
  My Data / 計測 / リードの描画には触れない
