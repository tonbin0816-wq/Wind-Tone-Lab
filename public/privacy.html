プライバシーポリシー

最終更新日: 2026年9月23日

Ficus（以下「本アプリ」）は、サックスの練習を記録・分析するためのアプリです。 本ポリシーは、本アプリが扱う情報とその扱い方を説明します。

1. 本アプリの基本的な考え方

本アプリの記録は、原則としてお使いの端末の中だけに保存されます。 録音した音声、計測したデータ、リードの記録、目安の値は、端末内のデータベース（IndexedDB）に保存され、 サーバーへは送信されません。

サーバーへ情報が送られるのは、「コミュニティ」タブに参加した場合だけです。 参加しなければ、本アプリはあなたに関する情報を一切サーバーへ送りません。

2. 収集する情報

コミュニティに参加した場合、以下の情報が Google の Firebase（Cloud Firestore / Firebase Authentication）に保存されます。

情報内容他の利用者から見えるか
匿名アカウントID Firebase の匿名認証が発行する識別子。氏名・メールアドレス・電話番号とは結び付いていません。 見えません
プロフィール ニックネーム（自由入力）、アイコン（あらかじめ用意した絵柄と色、またはご自分で選んだ写真1枚）、楽器種別、 楽器・マウスピース・リガチャー・リードの組、属性、演奏開始年、ジャンル、編成 「公開」を有効にしている間は見えます
練習の記録 端末内の記録から数えた練習した日数と練習した時間 （それぞれ1週間・1ヶ月・1年・累計）。録音そのものは送りません。 「公開」を有効にしている間は見えます
目安の数値 あなたの演奏の平均値（音程・音量・スペクトル重心・HNR・倍音構成）。音声ではなく数値です。 「公開」を有効にしている間は見えます
端末の種別 iOS / Android / PC のいずれか。機種名や広告IDは取得しません。 見えません
お問い合わせの内容 アプリ内の「お問い合わせ・要望/感想」から送った本文、送信日時、送信者の匿名アカウントID、端末の種別。 本文に何を書くかはご自身で決められます。氏名や連絡先を書く必要はありません。 見えません（運営者のみ）
通報の記録 他の利用者を通報した場合、通報した相手・理由・日時・通報者の匿名アカウントID 見えません（運営者のみ）
アイコンの写真 アイコンに写真を選んだ場合、その画像1枚（Cloud Storage for Firebase に保存）。 端末の中で正方形に切り抜き、256ピクセルの WebP 形式（WebP を作れない端末では JPEG 形式）に作り直してから送ります。 この作り直しで、撮影日時・撮影場所（位置情報）などの付帯情報（Exif）は取り除かれます。 保存の前に Google の Cloud Vision API による自動判定を行い、 判定を通らなかった画像は保存されません。 「公開」を有効にしている間は見えます

アイコンの写真に、自分以外の人が写っているものを使わないでください。 写真は公開プロフィールに表示されます。絵柄を選び直せばいつでも取り消せ、取り消すとサーバーからも削除されます。 運営者は、通報や確認の結果により、アイコンの写真を取り外すことがあります。

録音した音声そのものは、いかなる場合もサーバーへ送信しません。 端末の中で解析され、数値だけが記録されます。

3. 利用目的

  • コミュニティ機能（他の奏者のデータの閲覧、練習記録のランキング、機材の傾向の集計、目安の共有）の提供
  • アイコンの写真が本アプリで使える内容かどうかの自動判定（Google の Cloud Vision API を利用します）
  • お問い合わせ・ご要望への対応と、本アプリの改善
  • 不適切な利用への対応（通報への対処）

上記以外の目的には利用しません。

4. 第三者への提供

取得した情報を第三者へ販売・提供することはありません。 ただし、データの保存先として Google の Firebase を利用しています（Google LLC）。 アイコンの写真の自動判定にも同社の Cloud Vision API を利用します（判定のために画像が同社へ送られます）。 また、法令に基づく開示請求があった場合はこの限りではありません。

現在、本アプリは広告を表示していません。 広告ネットワークや解析サービスへの情報提供もありません。 将来これを変更する場合は、変更前に本ポリシーを改定し、本アプリ内でお知らせします。

5. 公開の停止と削除

  • 公開の停止: コミュニティタブの「マイページ」で「公開」をオフにすると、 プロフィール・練習の記録・目安が他の利用者から見えなくなります。目安はサーバーからも削除されます。
  • アイコンの写真の削除: アイコンの絵柄を選び直すと、写真はサーバーから削除されます。
  • アカウントの削除: 同じ画面の「アカウントを削除」で、 サーバー上のプロフィール・練習の記録・目安・アイコンの写真・匿名アカウントを完全に削除できます。 端末内の記録（計測・リード・目安）はこの操作では消えません。
  • 削除しても残るもの: 送信済みのお問い合わせと通報の記録は、 対応の履歴として運営者の側に残ります。これらの削除もご希望の場合は、下記の連絡先へお知らせください。
  • お問い合わせによる削除請求: 下記の連絡先へご連絡いただければ対応します。

なお、匿名アカウントはお使いの端末に紐づいています。 機種変更やアプリの削除でアカウントは失われ、元に戻せません。

6. 年齢について

本アプリのコミュニティ機能は13歳以上の方を対象としています。 参加時に年齢の確認に同意していただいています。
